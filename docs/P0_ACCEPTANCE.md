# P0: первый настоящий рейс

Этот документ фиксирует, как интегрирован модуль TruckProfit в действующий Fleet Economics. Веб-кабинет, Supabase Auth, tenant model и Vercel-проект сохранены. Не используется отдельная demo-база или второй источник данных.

## Что добавлено

- точный TypeScript calculation layer: `money`, `mileage`, `driver-compensation`, `trip-pnl`;
- расчёт на целых minor units и неизменяемые P&L snapshots;
- отдельная проверка расхода водителя: `PENDING`, `APPROVED`, `REJECTED`;
- команды Telegram для начала и завершения плеча с одометром;
- закрытие рейса только после фактического завершения каждого плеча;
- защищённый webhook `POST /api/telegram` с Telegram secret token;
- audit для старта/завершения плеч, review расхода, закрытия рейса и публикации P&L.

## Порядок запуска

1. Применить `supabase/migrations/00005_trip_pnl_snapshots.sql` в Supabase SQL Editor.
2. В Vercel добавить secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `SUPABASE_SERVICE_ROLE_KEY`.
3. Настроить Telegram webhook на `https://fleet-economics.vercel.app/api/telegram` с тем же secret token.
4. Создать машину, водителя и активный рейс в кабинете.
5. Создать одноразовое приглашение водителю; водитель открывает ссылку и связывает Telegram.
6. Водитель запускает плечо: `/legstart 523840 loaded`, завершает: `/legfinish 525050`.
7. Водитель передаёт расход через меню бота. Владелец принимает или отклоняет его на dashboard.
8. Владелец вносит доход, закрывает рейс и нажимает «Создать P&L».

## Критерий готовности

P0 считается подтверждённым только когда один реальный рейс проходит все шаги выше, а итог P&L совпадает с ручным расчётом до одного тиына. Неподтверждённый расход, незавершённое плечо или `UNKNOWN` load state должны блокировать финальный расчёт.

## Ограничения P0

- один тягач и один основной водитель на рейс;
- финальный P&L в базовой валюте организации;
- `management profit` — управленческий результат рейса, а не бухгалтерская чистая прибыль компании;
- n8n остаётся дополнением для уведомлений и импорта, но не хранит финансовые факты или Telegram-состояние.
