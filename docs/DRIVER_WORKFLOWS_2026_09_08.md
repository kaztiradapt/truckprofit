# Сценарии водителя — 08.09.2026

## Добавлено

- Мастер расхода: категория, валюта чека, сумма, ручной курс к базовой валюте компании, литры для топлива, одометр, предпросмотр. Кнопки «Назад», исправление полей, отмена.
- KZT/RUB/USD/CNY/UZS. Исходные значения сохраняются в receipt_amount/receipt_currency/receipt_fx_rate. expenses.amount/currency и reporting_amount_minor остаются в валюте компании; отчёты не суммируют несопоставимые валюты.
- «Мои расходы»: записи текущего активного рейса по 10 на страницу, чеки из приватного хранилища, исправление суммы/валюты/курса/литров и просмотр последних 10 исправлений. Только собственные Telegram-расходы активного рейса. Одометр и категория сохранённой записи не меняются. Закрытые рейсы водителю редактировать нельзя.
- Принятие назначения или отказ с причиной 3–500 символов. Это отдельный факт от статуса движения; отказ не отменяет рейс. Ответ виден в Mini App и списке активных рейсов бота. При смене машины/водителя токен назначения меняется, старые кнопки перестают работать.
- Доступ к персональным данным бота только из личного чата. Ошибка подтверждения callback не теряет действие: повторная обработка защищена журналом идемпотентности.

## База и выпуск

Миграция 00042_driver_workflows.sql применена транзакцией в Supabase ifmyyigekuomngkgcqgk через SQL Editor. Новые функции доступны только серверной service_role; дополнительных публичных политик доступа нет. Исторические суммы не пересчитывались, рабочие записи не удалялись. У прежних назначений начальное значение PENDING.

При повторном развёртывании сначала сверить миграцию 00042 и объекты, не выполнять её повторно. Код требует эту миграцию. Секреты и новые платные интеграции не добавлены.

## Проверки и ограничения

Автоматические тесты используют изолированный PostgreSQL и подменённый Telegram-транспорт, не рабочие расходы клиентов. Проверяются конвертация и округление, некорректные валюты/числа, идентификация личного Telegram, запрет чужих/закрытых/устаревших исправлений, audit before/after, повторы update, принятие/отказ и старые кнопки, неизменность одометра.

Сборка, типы, lint и 6 браузерных тестов скачивания отчётов прошли. Физический прогон в Telegram на телефоне пока не выполнен.

«Мой рейс» по-прежнему выбирает последнее активное назначение. Для нескольких одновременных активных рейсов одному водителю потребуется отдельный выбор рейса. Курсы вводятся вручную, онлайн-источник курсов не подключён. Внешняя отправка файла Telegram может повториться при сетевом сбое; сами расходы не дублируются.

Контроль после публикации: /start → Мой рейс → Принять; Добавить расход → валюта → сумма → курс → одометр → исправление поля → сохранить → фото; Мои расходы → чек → исправить сумму → история; в кабинете проверить исходную/учётную сумму и принятие назначения. Не использовать реальные расходы для пробных записей.
