# Обучающие ролики TruckProfit

Исходник видеоинструкции «Первый рейс: от создания до отчёта». Ролик собран из восьми редактируемых сцен в Remotion, использует только демонстрационные данные и включает русскую озвучку и субтитры.

## Commands

Установить зависимости:

```console
npm i
```

Открыть редактор и предпросмотр:

```console
npm run dev
```

Проверить код:

```console
npm run lint
```

Пересоздать живую ИИ-озвучку (требуется `OPENAI_API_KEY`):

```console
npm run voiceover
```

Отрендерить основной ролик:

```console
npm run render:first-trip
```

Озвучка создаётся моделью `gpt-4o-mini-tts`, голосом `marin`. Готовое видео и постер сохраняются в `output/`. Копии для сайта находятся в `../public/training/`.
